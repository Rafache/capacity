# Agent instructions

Before making any change in this repository, read `CONTRIBUTING.md` in full and follow it as the source of truth for contribution rules.

In particular:

- keep the application intentionally small and simple;
- follow the documented code and data conventions;
- run `npm run check` after code changes and before considering a pull request ready;
- do not claim a change is complete while required checks are failing;
- inspect the Cloudflare branch preview when the change affects user-visible behavior or layout;
- keep each pull request focused on one coherent objective.

If these instructions conflict with `CONTRIBUTING.md`, `CONTRIBUTING.md` takes precedence.
